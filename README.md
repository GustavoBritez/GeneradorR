Este programa es un creador de instalador/reinstalador.

Para usarlo se debe descargar este proyecto
Ejecutar el .exe
Descargar tu proyecto de trabajo y diploma desde github como .zip
Arrastrar el archivo .zip de tu trabajo de diploma hacia el formulario del generador
Selecionar el boton "Compilar y Generar"
Listo.

Se creara una carpeta por defecto con nombre "instaladores" en tu escritorio con todo lo necesario para instalarlo en un equipo.
